# Student Planner

A simple, responsive student planner built with **HTML, CSS, and JavaScript**.

## Features
- Add study tasks with a subject and due date
- Mark tasks as completed
- Filter all, pending, and completed tasks
- Delete tasks
- Track total, completed, and remaining tasks
- Save quick notes and set a daily study goal
- Automatically saves data in your browser using localStorage
- Mobile-friendly layout

## Run on your computer
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation is required.

## Upload to GitHub
1. Create a GitHub repository named `1-student-planner-saas` (or choose your own name).
2. Extract this ZIP file.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's main branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then click **Save**.
7. Wait for GitHub Pages to publish your website.

## Note
Tasks and notes are stored in the browser on the device you use. They are not synced to an online account or database.
